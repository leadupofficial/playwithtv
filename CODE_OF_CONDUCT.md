# Code of Conduct

Play With TV is a family-friendly project, and we want everyone to feel welcome here.

## Our standards

- Be respectful and patient, especially with newcomers and non-coders.
- Give and take feedback about the work, never about the person.
- No harassment, insults, discrimination, sexual content or personal attacks, in public or private.
- Don't share other people's private information.

## Enforcement

Maintainers may edit or remove comments, code or issues that break these rules, and may temporarily or permanently
ban anyone whose behaviour is harmful.

Report problems privately to the maintainers through a GitHub security advisory on this repository
(**Security → Report a vulnerability**, and mark it as a conduct report) or by messaging a maintainer directly.
Reports are kept confidential.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
